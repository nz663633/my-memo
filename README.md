## My-Memo

A simple memo management website
간단한 메모 작성 및 관리 웹사이트

---------

### Live Demo

[My-Memo](https://heroic-solace-production-c68d.up.railway.app)

---------

### Tech Stack

* **Frontend:** React
* **Backend:** Node.js, Express
* **Database:** MySQL

---------

### Key Features

- User registration
- User login and logout
- Session-based authentication
- Create memos
- View memos
- Update memos
- Delete memos
- User-specific memo management
